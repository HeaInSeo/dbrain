# Agent Bootstrap Contract — Working Candidate

Bootstrap Prompt tells a fresh agent **how to use the Brain**.

Brain/declared authority tells the agent **what is authoritative**.

```text
Bootstrap delivered != Context Ready
Context Ready != Role Qualified
Role Qualified != Task Admitted
Task Prompt delivered != Execution Authorized
```

Prompt families remain distinct:

1. Agent Bootstrap Prompt
2. Qualification Candidate Prompt
3. Qualification Evaluator Prompt
4. Task / Implementation-Packet rendering
